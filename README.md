# PiratesNodes

Custom Minecraft hosting panel starter for GitHub.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Important

This repository is a UI/buildable starter. It does not provision real Minecraft servers, process real payments, or provide real authentication yet. Those require a backend, database, payment provider, and a secured VPS node agent.

Do not put VPS passwords, API keys, payment secrets, or database passwords in GitHub. Use environment variables/secrets.
